## Codescan
* **Category:** Misc
* **Author:** msanft

I contributed my very own bit of security to a C (unsafe!) project by future-proofing it with running `svelte-check` in case any Svelte files are ever added.

You need to get access to your team's private upstream repository in the [ecsc-2026-codescan](https://github.com/ecsc-2026-codescan) GitHub organization. Connect to the signup service and enter one GitHub username to request access. Accept the GitHub organization invitation before cloning.

The signup service accepts one connection per instance. Recreate your instance if you need another attempt. Anyone who knows your team's signup address can use that one chance, so keep the address private.
