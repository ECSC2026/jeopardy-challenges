# ECSC 2026 - Jeopardy Challenges

This repository contains the jeopardy challenges that were released during [ECSC 2026](https://ecsc2026.de).

The jeopardy CTF lasted from 10:00 to 22:00, and multiple waves of challenges were released. 42 teams participated in the competition.

The folders in the challenge directories have the following meaning:
* **public:** the handout that was given to the players
* **deploy:** the Dockerfile that was used to host the challenge
* **build:** the source code that was used to compile the challenge
* **solution:** a solve script or short writeup
